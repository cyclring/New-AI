# AI 어시스턴트 (어시)

Claude Code와 Codex가 같은 메시지를 받아 협업하는 Windows 앱입니다. 왼쪽에서 폴더와 채팅을 고르고 가운데에서 메시지를 보냅니다. 기존 Claude 및 Codex 앱의 채팅은 별도로 사용합니다.

## 사용하기

1. Git, .NET 10 Desktop Runtime, 로그인된 Claude Code CLI와 Codex CLI가 필요합니다. CLI 실행 파일은 기본 설치 경로와 PATH에서 자동 검색하며, 직접 지정하려면 왼쪽의 **CLI 설정**을 펼칩니다.
2. **폴더 열기**로 일반 폴더 또는 로컬 Git 저장소를 엽니다. 폴더 없이 대화를 시작할 수도 있습니다.
3. 메시지를 보내면 두 AI가 먼저 동시에 의견을 냅니다. **협업 과정**을 펼치면 두 AI의 의견과 작업 진행을 볼 수 있습니다. 채팅 본문에는 대표 답변 하나가 올라옵니다. 한 AI가 실패하면 협업 과정에 오류를 표시하고 가능한 경우 다른 AI의 답을 보여줍니다. Enter는 보내기, Shift+Enter는 줄바꿈입니다.
4. 파일을 수정하려면 메시지를 보내기 전에 **코드 작업**을 켭니다. 입력창 아래에서 구현 담당을 고릅니다. 다른 AI는 이번 메시지에서 생긴 변경만 검토하며, 수정 요청이 있으면 구현 담당이 한 차례 반영합니다. 작업 폴더는 **작업 폴더** 버튼으로, 패치는 **변경분 저장** 버튼으로 확인합니다.

일반 폴더는 별도 위치에 복사해 내부 비교용 Git 커밋을 만듭니다. 복사할 때 심볼릭 링크와 접합점은 건너뜁니다. 기존 Git 저장소는 현재 커밋에서 별도 worktree를 만드므로 원본의 미커밋 파일은 포함되지 않습니다. 작업 변경은 원본에 자동 적용하지 않습니다. 채팅과 세션 정보는 로컬의 어시 데이터 폴더에 저장됩니다. 일반 폴더를 복사할 때 빌드 산출물, .gitignore에 맞는 항목, 잠긴 파일을 제외합니다. 작업 폴더는 종료 후에도 남으며, 패치를 저장한 뒤 작업 폴더 정리 버튼으로 지울 수 있습니다.

CLI 연동 참고 자료는 [OpenAI Codex 비대화형 모드](https://learn.chatgpt.com/docs/non-interactive-mode)와 [Claude Code CLI](https://code.claude.com/docs/en/cli-reference)입니다.
